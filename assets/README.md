# dcs2psvr2-shaker artwork

Original off-white S with cyan vibration ripples on charcoal, without Sony or
PlayStation imagery. `dcs2psvr2-shaker.png` is the master and `dcs2psvr2-shaker.ico`
contains Windows icon sizes. Run `python scripts/build-icon.py` from the repository
root (requires Pillow) to regenerate the ICO. Builds use the committed ICO.
Artwork is distributed under the project's GPL-3.0 license.

`social-preview.jpg` is the README banner. `support/` holds the README support
buttons, built from the logos and colours in `support/content.json` and `support/assets`.
